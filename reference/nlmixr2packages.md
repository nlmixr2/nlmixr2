# List all packages in the nlmixr2

List all packages in the nlmixr2

## Usage

``` r
nlmixr2packages(include_self = TRUE)
```

## Arguments

- include_self:

  Include nlmixr2 in the list?

## Examples

``` r
nlmixr2packages()
#>  [1] "clisymbols"   "cli"          "crayon"       "dplyr"        "purrr"       
#>  [6] "rstudioapi"   "nlmixr2est"   "nlmixr2extra" "rxode2"       "lotri"       
#> [11] "nlmixr2plot"  "tibble"       "nlmixr2save"  "nlmixr2"     
```
